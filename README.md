## ABOUT HAILSTONES

Hailstones is a developer and digital creator focused on software development, artificial intelligence, web technologies, and interactive game experiences.

My work involves exploring technical concepts, developing digital products, and building projects that combine functionality with engaging user experiences.

One of my principal projects is the **GHOST CTS series — Code to Survive**, a browser-based game series that brings action and survival gameplay together with Python programming challenges.

I continue to develop my skills through practical projects, experimentation, and exploration of emerging technologies.
